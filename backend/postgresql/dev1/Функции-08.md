# SQL-функции

Функции нужны для упрощения задачи. Большая задача делится на мелкие, которые решаются благодаря функциям. Это позволяет концентрироваться на конкретном узле. Функция вызывается в контексте какого-либо выражения (select, from, where, check и тд)

Мы должны определить интерфейс функции (решает конкретную задачу, принимает на вход данные [параметры], что-то делает и что-то возвращает в качестве результата). После определения интерфейса можно модифицировать реализацию (тело задачи).

Функция, с точки зрения БД, это объект БД. Инфо о ней хранится в системном каталоге (pg_proc -- неточное название)

Основные составные части определения: имя, параметры, тип возвращаемого значения, тело.

Функция - это примерно строка, которая в таком виде хранится в pg.

#### Пример функции без параметров, содержащей один оператор

```SQL
RETURNS text -- тип возвращаемого значения
CREATE FUNCTION hello_world() -- имя и пустой список параметров
AS $$ SELECT 'Hello, world!'; $$ -- тело
LANGUAGE sql; -- указание языка
```

Тело удобно записывать в строке, заключённой в кавычки-доллары, как в приведённом примере. Иначе придётся заботиться об экранировании кавычек:

`SELECT ' SELECT ''hello, world!''; ';`

`SELECT $$ SELECT 'H W'; $$;`

При необходимости кавычки-доллары могут быть вложенными. Для этого в каждой паре кавычек необходимо использовать разный текст между долларами.

`SELECT $func$ SELECT $$Hello, world!$$; $func$;`

#### Создание функции по стандарту SQL

```SQL
CREATE OR REPLACE FUNCTION hello_world() RETURNS text
LANGUAGE sql
RETURN 'Hello world!';
```

#### Вызов функции

```SQL
SELECT hello_world()
```

#### Хранение тела функции в системном каталоге

```SQL
SELECT proname, prosrc, prosqlbody FROM pg_proc WHERE proname = 'hello_world'
```

#### Получить исходный код функции (PSQL)

`\sf` - возможность посмотреть исходный текст функции

```SQL
selectel=# \sf hello_world
CREATE OR REPLACE FUNCTION public.hello_world()
 RETURNS text
 LANGUAGE sql
RETURN 'Hello, world!'::text
```


Если тело функции состоит из нескольких операторов SQL, в качестве результата возвращается значение из первой строки, которую вернул последний оператор. Если код такой функции написан в стиле стандарта SQL, потребуется использовать конструкцию BEGIN ATOMIC ... END, которая охватывает выполняемый блок операторов:

```SQL
CREATE OR REPLACE FUNCTION hello_world() RETURNS text
LANGUAGE sql
BEGIN ATOMIC
	SELECT 'First Line';
	SELECT 'Second Line'; -- вернётся это
END;
```

#### Функция с параметром

```SQL
CREATE FUNCTION hello(name text)
RETURNS text
LANGUAGE sql
RETURN 'Hello, ' || name || '!'
```

#### Удаление функции

```SQL
DROP FUNCTION hello(text)
```

#### Функция с IN (входные параметры)

```SQL
CREATE FUNCTION hi(IN name text, IN greet text DEFAULT 'Dear', IN title text DEFAULT 'Mr')
RETURNS text
LANGUAGE sql STRICT -- строгая функция
RETURN 'Hello, ' || greet || ' ' || title || ' ' || name || '!';

-- вызов
SELECT hi('Alice', 'Charming', 'Mrs')

-- явный вызов
SELECT hi(title => 'Mrs', name => 'Alice')
```



- STRICT говорит, что если в одном из входных параметров при вызове функции будет неопределённое значение, то функция не будет вызываться и будет значение .
